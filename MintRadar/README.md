# MintRadar — app source

The documentation lives in the repository root: **[../README.md](../README.md)**.

This directory holds the application code (frontend in `src/`, backend in `backend/`, end-to-end tests in `e2e/`, deployment config in `deploy/`, docs in `docs/`). The public API is documented in [docs/API.md](docs/API.md).

Dashboard URL parameters (such as `?testmints=hide` and `?outdated=hide`, which hides mints with outdated software) are listed in the root README, section "Dashboard & Discovery".
